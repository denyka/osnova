# Security

Report a vulnerability privately: on GitHub through "Report a vulnerability"
under the repository's Security tab, on GitLab through a confidential issue.
Never open a public issue for it. Include the affected version, how to
reproduce it and the impact you see. You get an acknowledgement within seven
days and a fix or a decision within thirty.

Secrets never live in this repository: keys, tokens and passwords travel
only through the maintainer's encrypted archives. A secret found in history
is rotated first and removed second.
